# TrustLens Brand Assets

Place the official TrustLens brand assets in this folder:
- `trustlens-logo.svg` (SVG vector master combining Shield, Magnifying Glass, Checkmark, and Data Visualization bars)
- `trustlens-logo.png` (Optional raster export for high-resolution favicon and OpenGraph embeds)

## Brand Identity Specification:
- **Symbol Elements:**
  1. Shield — Trust and protection
  2. Magnifying Glass — Scientific investigation
  3. Checkmark — Fact verification
  4. Data Visualization — Statistical and empirical evidence analysis
- **Primary Navy:** `#0B1220`
- **TrustLens Teal:** `#14B8A6`
- **Light Background:** `#F8FAFC`
- **Dark Background:** `#090F1A`
- **Primary Text:** `#0F172A`
- **Secondary Text:** `#64748B`
- **Border:** `#E2E8F0`
